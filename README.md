# Капитал — читалка по главам

Скрипт `parse.py` скачивает «Капитал. Полная квинтэссенция 3-х томов» (Маркс, Борхардт) с loveread.ec, режет на главы и собирает:

- `kapital.html` — офлайн-читалка с оглавлением, тёмной темой и запоминанием места;
- `kapital.txt` — то же простым текстом.

Нужен Python 3, сторонних библиотек нет.

```
python parse.py
```

Потом открыть `kapital.html` в браузере.
